# Backup Monitor

**A local-first backup monitoring dashboard for Windows.**

Backup Monitor helps an IT team quickly see which computers have recent backups and which need attention. It combines a lightweight browser dashboard with a PowerShell reporting process and an Excel report.

## What it does

- Summarizes the latest backup status for monitored computers.
- Highlights operational, warning, and error states.
- Lets users search and filter the equipment list.
- Refreshes backup information on demand and updates an Excel report.
- Provides a Spanish/English interface.
- Runs locally on Windows; the dashboard is not exposed to the public internet.

## Built with

Python, PowerShell, HTML, CSS, and JavaScript.

I designed and developed the application, including its local web server, dashboard, backup-reporting workflow, and Excel output.

# Backup Monitor (Español)

**Panel local de supervisión de copias de seguridad para Windows.**

Backup Monitor permite consultar rápidamente qué equipos tienen copias recientes y cuáles necesitan atención. Combina un panel web ligero con un proceso de informes en PowerShell y un informe Excel.

## Funcionalidades

- Resumen del estado de las copias más recientes.
- Identificación de estados operativos, de advertencia y de error.
- Búsqueda y filtrado de equipos.
- Actualización bajo demanda y generación de un informe Excel.
- Interfaz en español e inglés.
- Ejecución local en Windows, sin exponer el panel a Internet.

El código fuente y los detalles operativos permanecen privados por tratarse de una herramienta desarrollada para un entorno interno.
